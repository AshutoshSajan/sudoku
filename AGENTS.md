# AGENTS.md — hard rules for agents working in this repo

Self-sufficient. Follow these verbatim; depth lives in [CONVENTIONS.md](CONVENTIONS.md).

## Hard rules (inline — compliance does not require opening any other file)

1. **Two trunks only: `dev` (integration) and `main` (deployable).** Neither is
   ever worked on directly: no local commits, pushes, merges, force-pushes,
   resets, or deletions against `main`/`dev`. Trunk changes come only from
   merged PRs (GitHub "Create a merge commit" — squash/rebase merges violate
   this; CI fails them).
2. **Branch model:** name task branches `feat/* fix/* chore/* ci/* docs/*
   perf/* refactor/* test/* release/*` (retired: `feature/*`, `bugfix/*`,
   `hotfix/*`), cut them **from `origin/dev`**, and open the PR **into `dev`**:
   `git push -u origin <branch> && gh pr create --base dev`.
   `dev` reaches `main` only via a release PR (merge commit, no squash).
3. **No destructive database operations, ever.** No dropping `*.db`/store
   files/tables, no `TRUNCATE`, no bulk deletes, no reversed or destructive
   migrations — additive schema changes only.
4. **No secrets in the repo.** Env files stay local (`.env.example` is the
   only commit-able artifact); keys/keystores/tokens go to repo Settings.
5. **Generated files are regenerated by tooling, never hand-edited**:
   `CHANGELOG.md` (git-cliff), `pubspec.lock` (`flutter pub get`), gradle
   wrapper outputs, `extension/app/`.
6. **Verify before every push:** enable the hooks once per clone with
   `git config core.hooksPath .githooks`, then run `bash tool/verify.sh`
   (flutter analyze + flutter test). `.githooks/pre-push` refuses any push
   that carries `refs/heads/main` or `refs/heads/dev` (including `--force`
   and deletion forms) and runs the gate. Hook bypasses (`--no-verify`) are
   deliberate, stated exceptions only.
7. **Don't touch other sessions' uncommitted work.** If a checkout is being
   used by another session/agent, do your work in `git worktree add
   ../sudoku-<branch> <branch>` instead.
8. **Dependencies:** only GPL-3.0-compatible licenses; update
   `pubspec.lock` via `flutter pub get` (never hand-edit); run
   `bash tool/deps.sh`; Dependabot/CI PRs into `dev` merge with merge commits.

## Command map

```sh
git config core.hooksPath .githooks   # one-time per clone (hooks)
bash tool/verify.sh                   # analyze + test (the push gate)
bash tool/deps.sh                     # dependency audit (osv-scanner, pinned)
                                        # add --offline to skip all network work
mise x shellcheck@0.11.0 -- shellcheck .githooks/*  # shell lint
mise x actionlint -- actionlint       # workflow lint (CI parity)
git tag vX.Y.Z <newest-main-merge-commit-without-[skip-ci]>  # releases
```
